# Виджет FitLog через Scriptable

Веб-сводка и график доступны независимо от виджета. Scriptable получает ту же
числовую сводку через отдельный доступ только для чтения. Собственное приложение,
Xcode и Apple Developer аккаунт не нужны.

## Установка на iPhone

1. Дождитесь успешного обновления сервера FitLog: одного push на GitHub
   недостаточно, сборка и деплой должны закончиться.
2. Установите [Scriptable](https://apps.apple.com/app/scriptable/id1405459188)
   из App Store и откройте его один раз.
3. В Safari откройте свой FitLog → **Сводка** → **Виджет через Scriptable**.
4. Нажмите **Скопировать скрипт**. В Scriptable нажмите **+**, вставьте код,
   назовите скрипт **FitLog** и сохраните. Альтернатива: **Скачать FitLog.js**,
   затем в «Файлах» перенести файл в **iCloud Drive → Scriptable**. Скрипт также
   находится в репозитории: [`web/public/scriptable/FitLog.js`](../web/public/scriptable/FitLog.js).
5. Вернитесь на страницу Сводки, нажмите **Создать ключ виджета**, затем
   **Скопировать ключ**. Для этого нужно войти в FitLog обычным способом.
6. Запустите **FitLog** в Scriptable кнопкой ▶. В окне подключения укажите
   HTTPS-адрес своего сервера **без `/dashboard`**, например
   `https://fitlog.example.com`, и вставьте ключ виджета. Нажмите **Подключить**.
   Это пример адреса: нужно использовать адрес своего FitLog.
7. Дождитесь предпросмотра с цифрами. Если подключения нет, проверьте интернет,
   адрес, завершение деплоя и правильность ключа. Основной токен входа сюда
   вставлять не нужно.
8. На главном экране iPhone удерживайте пустое место → **Изменить / Добавить
   виджет** (название зависит от iOS) → **Scriptable** → выберите **большой**
   размер → **Добавить виджет**.
9. Удерживайте добавленный виджет → **Изменить виджет** → **Script: FitLog**.
   Поле **Parameter** оставьте пустым. Закройте настройки.

Большой виджет показывает 24 показателя и ближайшую тренировку. Маленький
показывает 4 показателя, средний — 8. Графиков в виджете нет. Нажатие открывает
веб-сводку. Даты восстановления, сна, питания и измерения тела отображаются
отдельно; ноль не подменяется отсутствием данных.

Для отдельного блока задайте **Parameter**: `recovery`, `sleep`, `training`,
`nutrition` или `body`. В маленьком размере помещаются первые четыре показателя
выбранного блока. Тренировки считаются за последние семь местных календарных
дней, включая сегодня, по завершённым сессиям.

## Обновление и повторное подключение

Скрипт просит обновление не раньше чем через 30 минут. Фактическое расписание
определяет iOS: точный интервал не гарантируется. Данные запрашиваются по сети;
скрипт не создаёт файл с сохранёнными медицинскими данными и не показывает
выдуманные значения при ошибке. Отсутствие данных обозначено `—`.

Для ручной проверки откройте Scriptable → FitLog → **Обновить и показать**.
Для смены адреса/ключа выберите **Подключить заново**. **Отключить** удаляет
сохранённые данные подключения из Keychain данного Scriptable; оно не отзывает
выданный ключ на сервере.

Ключ действует 90 дней и хранится в Keychain. Когда он истечёт, создайте новый
на странице Сводки и подключитесь заново. Создание нового ключа не отзывает
предыдущие. Смена `FITLOG_DASHBOARD_TOKEN` с перезапуском сервера делает
недействительными все ключи виджетов и текущие браузерные сессии.

## На Mac

Используйте передачу виджета с iPhone: macOS Sonoma или новее, iOS 17 или новее,
один Apple Account, iPhone рядом или в той же сети Wi-Fi. На Mac откройте
**Системные настройки → Рабочий стол и Dock → Виджеты → Использовать виджеты
 iPhone**, затем **Изменить виджеты** на рабочем столе и найдите Scriptable.
Настройка и выполнение скрипта происходят на iPhone. Доступность конкретного
виджета нужно проверить на устройствах; локальные проверки проекта этого не
подтверждают. [Инструкция Apple](https://support.apple.com/en-us/108996).

## API и границы проверки

- `POST /api/v1/auth/widget-token`: требует браузерную сессию владельца и
  `X-Fitlog-Request: 1`; возвращает `access_token`, `expires_at`, `scope`.
- `GET /api/v1/widget`: принимает `Authorization: Bearer <ключ виджета>`;
  возвращает ту же сводку, что защищённый `/dashboard/summary` API.
- Доступ ограничен `widget:read`. Ключ нельзя использовать для записи,
  выдачи других ключей или вместо cookie основной сессии. Все ответы `no-store`.
- Скрипт разрешает только HTTPS origin без пути, запрещает перенаправления,
  ограничивает запрос 15 секундами. Токены не включаются в URL и файл скрипта.
- Проверки Go покрывают срок, ротацию, назначение ключа и ограничения маршрутов.
  JS-проверки выполняют реальный файл скрипта с тестовыми API Scriptable и
  проверяют размеры, запросы и ошибки. Это не проверка внешнего приложения:
  отображение и обновление на реальном iPhone/Mac проверяются после установки.

Документация Scriptable: [виджеты](https://docs.scriptable.app/listwidget/),
[HTTP-запросы](https://docs.scriptable.app/request/),
[Keychain](https://docs.scriptable.app/keychain/).
